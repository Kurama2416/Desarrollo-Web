# Retrospectiva Sprint 3 – Manglü

## Retrospectiva Starfish

### ⭐ Keep Doing – Seguir haciendo

* Mantener la organización del proyecto mediante carpetas para separar las vistas, archivos estáticos y componentes reutilizables.
* Continuar utilizando EJS para generar contenido dinámico a partir de los datos almacenados en `data.js`.
* Mantener el uso de componentes reutilizables como `head.ejs`, `header.ejs` y `footer.ejs`.
* Realizar pruebas de las funcionalidades después de cada cambio para comprobar que el sistema continúe funcionando correctamente.

### 🛑 Stop Doing – Dejar de hacer

* Evitar repetir código HTML que pueda convertirse en un componente reutilizable.
* Evitar modificar directamente los archivos originales de Sprint 2 cuando sea posible conservarlos como referencia.
* Dejar de realizar cambios grandes sin probar primero las funcionalidades afectadas.

### ➕ Start Doing – Empezar a hacer

* Empezar a documentar los cambios realizados durante cada Sprint.
* Implementar nuevas funcionalidades utilizando rutas y vistas separadas para mantener el código organizado.
* Realizar pruebas de creación y edición de productos después de implementar cada funcionalidad.
* Utilizar Git para registrar los avances importantes del proyecto.

### 🔄 More Of – Hacer más

* Hacer más pruebas de las rutas de la aplicación, especialmente las relacionadas con productos.
* Aprovechar más los componentes reutilizables de EJS para evitar duplicación de código.
* Revisar periódicamente la estructura del proyecto para mantener una organización adecuada.
* Realizar más pruebas visuales para garantizar que las nuevas páginas mantengan el estilo de Manglü.

### 🔽 Less Of – Hacer menos

* Hacer menos cambios directamente sobre archivos que ya funcionan sin comprobar primero sus posibles efectos.
* Reducir la duplicación de código entre las diferentes páginas.
* Reducir los cambios innecesarios en los estilos y conservar los elementos visuales que ya funcionan correctamente.
* Evitar trabajar sin registrar los avances importantes en Git.

## Conclusión

Durante el Sprint 3 se logró avanzar en la transformación del proyecto Manglü hacia una aplicación web utilizando Node.js, Express y EJS. Se implementaron vistas dinámicas, componentes reutilizables y funcionalidades para consultar, crear y editar productos.

Como equipo, se identificó la importancia de mantener una estructura organizada, realizar pruebas constantes y documentar los avances para facilitar el desarrollo de futuras funcionalidades.
